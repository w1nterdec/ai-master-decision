# 研究资料来源与使用边界

本目录用于复现研究过程，不是一套已完成统一开源授权的招生数据库。根目录 MIT 许可适用于项目原创代码和原创文档，**不会替原权利人许可第三方资料**。

## 文件类型

- `raw/Phase3_7C_情景覆盖率门槛修复版.xlsx`：项目历史研究汇编，包含路径、来源编号、研究摘录、分析及公式。底层材料来自多个来源；尚无逐项完整的再分发授权记录。
- `raw/bupt_2027/*.txt`：北邮招生页面的历史文本快照。每份文件首行保留原文 URL。源站及其内容的权利归相应权利人；公开可访问不等于获得复制分发许可。
- `school_research_consolidated.json`：研究表的派生投影，207 条是逐路径映射，不是独立官方来源数；它不会因格式转换自动获得新的第三方授权。
- `raw/` 中的验证脚本、结果 JSON 和验收说明：工程复现材料；其中引用或嵌入的第三方内容仍遵从原来源条件。

## 如何使用

核对事实时优先打开官方来源，保留标题、机构、URL、年份与适用范围。来源编号没有对应原文链接的条目，应当先完成来源登记，再用于正式判断。

商业或非商业再利用，都需要按原来源条款和实际权利情况评估；本仓库不声称能够授予第三方材料的再分发权。项目也不声称任何高校为本系统背书。详细可追溯信息见 [数据来源清单](../docs/DATA_PROVENANCE.md)。

如发现资料归属、隐私或内容有问题，可通过仓库 Issue 提交文件路径与问题描述；涉及个人信息时不要在公开 Issue 粘贴原文，先请求私密联系渠道。

个人数据库、档案、演示状态与 `.env` 不属于应提交的研究资料，已配置 Git 忽略规则。不要把个人判断、凭据或本地导出文件放入 `raw/`。
