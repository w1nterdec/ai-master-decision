# 新手指南：从启动到记录一次选择

## 先看一个可运行的例子

安装 Python 3.11+，在仓库根目录创建虚拟环境、执行 `python -m pip install -e .`，再用该环境的 Python 执行 `scripts/start.py --demo`。

不需要密钥、不需要自己准备 Excel。原始材料已经入库；演示目录默认是 `data/demo/`。演示仅隔离数据库与个人档案，使用相同的历史研究 JSON，不会给空白指标编造评分。

打开网页后展开“新手入门与功能状态”，点击“先浏览研究样本”，搜索“具身”或“408”。每条资料可看到来源编号、原始状态、底稿表名、行号和适用限制。S2 学院级等标签不是核验通过标志。

## 录入个人条件

点击“填写个人条件与备考分层”，填写本科专业、目标方向、意向城市、可接受专业代码、预算与其他限制，点“保存个人条件”。

例如你可以写自己的预算上限、接受的科目与城市；系统不会替你补值。这里是个人上下文记录，**不会自动修改硬约束、权重、原案例政策或历史分析师意见**。网页仍有原始案例的只考一次等解释政策，新使用者必须核对适用性；通用条件驱动的引擎装配属于后续迭代。

## 选择具体路径

在院校探索按学校、培养地、第四单元科目和角色筛选。学校相同、专业相同但学院或方向不同，依然是不同路径。

打开对应路径的“历史研究资料”，先看原文与适用限制，再看已核验声明、名额口径和风险。将需要研究的路径加入候选、关注或对比，最多并列四条。标记不改变任何事实的核验状态。

## 把原始材料登记成证据

1. 高级功能 → 证据管理 → 来源登记：填写唯一编号、标题、发布机构、原文 URL 或文件标识、发布年份和适用招生年份。不要把访问时间当成适用年份。
2. 证据关联 → 登记事实声明：选择来源，写能在原件中定位的具体陈述，填写适用年份。
3. 同页下方关联到路径和三级指标。不要用全校就业报告直接证明某方向的名额或导师开放情况。
4. 人工核验：先核对来源本体，再核对声明及关联，记录操作者和核验依据。来源通过不等于所有关联声明自动通过；候选映射不得自动升级。
5. 存在冲突时保留双方记录，查清后再解决，不能覆盖不利事实。

网页提供来源/声明管理；新增招生路径目前需要编辑 Excel 的路径表后导入。有效评分尚无独立网页录入入口，**这一步仍是完整量化决策闭环的缺口**；仅录入来源不保证出现可比较分数。

## 理解权重与情景

动态决策树中，从当前配置派生一个用户版本，再用“当前偏好配置”选择它。调整相对权重并明确确认；保留演示基准便于比较。

当前数据模型主要用 `is_demo` 区分演示和用户版本，尚未独立建模“用户版本已确认”审批状态，因此不要仅凭版本名称判断偏好已经确认。

- 三级权重：例如先决定研究培养的重要性，再决定科研匹配与培养可进入性，最后才是具体指标。
- 情景分析：观察更看重职业、研究或报考时结果是否稳定；不会改变证据事实。
- 零权重组：页面会提示，表示该组不参与权重贡献，不是自动平均分配。
- 负权重或结构异常：显示明确错误；先备份再修复，或切换独立演示验证安装。

## 看懂结论与缺口

院校探索的“看懂当前结论：依据、缺口与风险”直接展示引擎已有的培养价值、一志愿价值状态及原因，没有增加第二套推荐公式。

有效证据覆盖率是**有有效依据支持的指标权重占比**，不是已经完成了多少择校工作，更不是录取把握。门槛默认 80%；覆盖率不足或资格待确认时，不输出可靠比较。不要把缺失项补零，也不要靠降低门槛制造结论。

驾驶舱和风险页的解释回答：为何继续研究、为何目前不能判断、哪些证据缺失、哪些路径风险已经记录。静态结果总览是原案例的人工意见，不会随个人条件输入自动重写。

## 如何记录冲稳保

本项目目前没有从成绩、分数线、招生规模自动计算冲稳保的算法。在我的决策档案中，你可以选择路径、人工选择“冲/稳/保”，填写理由和待核验前提，再保存并导出 Markdown。

理由可以描述你已核对了哪些材料、仍缺什么、哪些变化会让你撤回该判断。没有理由不能保存分层；删除路径理由时该分层也会清除。“保”不是录取保证，标签不会被传进引擎、改写资格或评分。

## 调剂和就业功能到哪一步

R7 只有路径角色、数据结构、状态接口和准备事项。调剂推荐算法、直接就业路径评分没有实现。风险页中的相应文字只是政策和缺口说明，不能当成已经生成了可执行的调剂名单或就业方案。

## 常见启动问题

- 端口被占用：`python scripts/start.py --demo --port 8503`。
- 只验证初始化：加 `--prepare-only`；不会启动浏览器服务。
- 配置未生效：启动器才自动读取 `.env`；进程环境变量会覆盖文件值；`--demo` 覆盖数据库与档案路径。
- 页面为空：确认启动器使用的数据库与服务环境一致。直接运行 Streamlit 需要先初始化数据。
- 手机无法访问：手机的 `localhost` 是手机本身，需要可达的服务器地址。默认仅绑定本机；本项目没有多用户权限隔离。
- Docker 无法连接 daemon：先运行 Docker Desktop/daemon，再执行 `docker compose config --quiet` 和构建启动命令。
