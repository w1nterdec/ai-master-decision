### C.1 可比较的已核实事实（A 类，2027）

| 比较项 | 方向01（P01） | 方向02（P02） |
|---|---|---|
| 方向名称 | 01 人工智能与信息网络 | 02 人工智能与大数据 |
| 目录计划人数 | **43**（含推免） | **89**（含推免） |
| ④ 初试第四单元 | **801 通信原理**（自命题） | **408 计算机学科专业基础**（全国统考） |

| 学位 | 专业学位 | 专业学位 |
| 2028 资格 | 待 2028 核验 | 待 2028 核验 |

### C.2 不能这样比（常见误判）

| 误判 | 为什么错 |
|---|---|
| 「方向02 考 408，所以方向02 更好」 | 408 只是**科目选择**，与培养质量、就业、导师资源**无已核实关联**。两者是不同维度。 |
| 「方向02 招 89 人 > 方向01 的 43 人，所以 02 更容易上岸」 | 89 与 43 都是**目录计划数（含推免）**；报考人数、推免占比、复试淘汰率**全部未知**。**人数多 ≠ 竞争小**。 |
| 「01 考 801 通信原理，我不是通信背景，肯定吃亏」 | 属于**推断**。信息与计算科学是否学过通信原理因人而异，需用户自行确认；且 801 是北邮自命题，其难度分布无公开材料可依。 |
| 「02 是大数据方向，更接近 AI」 | 方向名称不等于培养内容。**官方未提供任何方向培养方案**（B7），此判断无依据。 |

### C.3 应该这样比（按已核实 → 待核验 → 未知的证据顺序）

| 比较维度 | 当前可得结论 | 分级 |
|---|---|---|
| **初试科目差异** | 01 = 801（自命题，通信类）；02 = 408（全国统考，计算机学科基础）。**这是两条路径目前唯一可确证的实质差异** | **A** |
| **科目与用户背景的匹配** | 用户本科「信息与计算科学」，408 覆盖面与已学课程重合度可能更高；801 通信原理可能是全新科目。但**需要用户自评**，系统不代判 | **C 推断** |
| **备考资源可得性** | 408 全国统考，真题/资料公开且标准化；801 自命题，资料相对封闭 | **C 推断** |
| **名额规模** | 02 目录计划 89 > 01 的 43，**但均含推免，统考实际名额未知** | 数字 **A**，推论 **D** |

| **导师分布差异** | ❌ 官方目录不列导师，学院官网未取得，**无法比较** | **D** |
| **就业差异** | ❌ 仅有全校级 2022 届数据，**无法分方向比较** | **D** |

**C 节结论**：目前**唯一能确证的差异是初试第四单元（801 vs 408）**，而这一差异是**备考层面的**，不是**价值层面的**。因此系统**不能**判定方向01 与方向02 哪个更好——这个判断必须等 2028 目录 + 方向培养方案 + 导师名单到位后才能做。
