# 工程可行性与风险边界

## 本轮保护的核心规则

`src/decision_system/engine/` 和 `docs/decision_rules.md` 不变。个人条件、人工冲稳保保存于独立档案，不进入引擎评分或资格输入。新增解释只读取引擎已有状态、覆盖率与原因；未知不补零、候选不升级、年份严格匹配的规则保持生效。

## 启动、依赖与演示

`scripts/start.py` 读取可选 `.env`，已有进程变量优先；相对路径按仓库根目录解析；初始化已有原件后启动 Streamlit。`--demo` 默认使用独立数据库和档案，`--prepare-only` 支持不启动服务的验收。

`pyproject.toml` 声明运行时依赖，新增 python-dotenv 支持完整的环境文件语法；无 LLM SDK 或 API Key 要求。`.[dev]` 提供 pytest、Ruff。仍未提供完整跨平台哈希锁文件，不能宣称位级可重复构建。

## Docker 与 Compose

Dockerfile 使用 Python 3.12、明确工作目录、声明依赖和已入库研究文件、非 root 用户、持久化 `/state`、幂等启动与 HTTP 健康检查。Compose 仅发布本机端口，宿主端口可配置，容器内保持 8501；数据在命名卷而非镜像中。

HTTP 健康检查只能证明服务进程可响应，不能证明应用脚本已正确渲染。因此新增 `scripts/smoke_app.py`，从真实导航读取全部 9 个入口、再检查 5 个管理页，失败时返回非零。CI 在容器中执行它，不只看健康接口。

本地验证应区分 Compose 静态解析、镜像构建、容器启动、页面渲染四个层级。daemon 未运行时，只能完成静态解析和原生 Python 验证，不能把历史 CI 的成功当成本轮镜像已经验收。

## SQLite 与 PostgreSQL

个人、少量读者、低频写入可继续使用 SQLite。SQLite 允许多个读者，但同时只能有一个写入者；长事务或多人修改会遇到锁竞争。WAL 或 busy timeout 可以缓解部分问题，不能提供多写入者并行能力。

多人同时提交来源、分数、偏好，或多实例部署时，建议规划 PostgreSQL。当前 `DECISION_DB_PATH` 只接受 SQLite 文件，**没有可直接切换的 PostgreSQL 后端**。

迁移至少需要：数据库连接配置和驱动、SQLite 专属 PRAGMA 的隔离、约束/JSON/枚举兼容性验证、Alembic 迁移、数据搬迁、事务与并发测试。还需要身份/权限、审计操作者隔离，并把个人 JSON 档案迁入按用户隔离的数据库存储。只替换连接字符串不能解决问题。

现有个人档案采用原子替换以防写入截断，但多个会话同时保存仍可能最后写入覆盖，未实现跨会话合并或乐观锁。不要将单实例当作多人协作服务。

## 敏感信息与扫描范围

真实 `.env`、SQLite、备份、个人档案和演示目录被 Git 忽略；仅提交无凭据的 `.env.example`。没有硬编码数据库口令，默认数据库地址为本地文件，监听地址为本机，不属于外部凭据。

新增 `scripts/check_secrets.py` 检查已跟踪与未忽略新文本中的私钥头、常见 GitHub/AWS 凭据模式、带密码的 URL 和 `.internal/.corp/.local` 域名。报告仅输出文件、行号与规则名，不打印命中值。它不扫描 Git 历史、二进制原件或被忽略的个人文件，不能证明不存在所有类型的秘密；发布前仍需人工复核资料和 Git 历史。

独立认证代理 `secure_web_launch.py` 从环境变量读取口令，缺省拒绝启动；普通本地启动器并不自动启用该代理。不要把 `AUTH_PASS` 写进源码、Compose 明文配置或截图。对外部署仍需要 HTTPS、访问控制和个人数据隔离。

## 许可与公开发布

原创代码和原创文档现采用根目录 MIT 许可，并在 `pyproject.toml` 声明 SPDX 标识。第三方依赖仍按各自许可；研究原文、汇编中的外部材料和截图引用不因此被重新授权。边界见 `NOTICE`、`data/README.md` 和 `docs/DATA_PROVENANCE.md`。

默认背景已泛化为公开示例；个人条件由使用者自行填写。旧提交中的作者邮箱与原案例措辞仍属于公开历史，本次不强制改写历史或标签，本地生成提交使用 GitHub noreply 邮箱，但平台合并署名仍取决于账户设置，当前平台合并保留账户邮箱。隐私与报告渠道见 `PRIVACY.md`、`SECURITY.md`。

`check_secrets.py --history` 增加分支、标签、远端引用的可达历史检查，并检查 Excel 内部 XML。它仍是指定模式检查，不覆盖全部隐私、版权或二进制内容。
