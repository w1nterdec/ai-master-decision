  - 方向01「人工智能与信息网络」：目录计划 **43 人（含推免）**；④ **801 通信原理**；公共课 101/201/301(数学一)。

## 3. 其余四校（证据不足，如实登记）

UESTC / SEU / HFUT / SWJTU 在库内仅有**候选映射 / 未登记来源**占位，**无任何已核验声明**。因此：
- 不能给出任何"值得读 / 值得考"的可靠结论；
- 不能因资料少就给低分，也不能因北邮资料多就自动认定更好（任务明确要求）。
- 系统对所有四校统一显示「培养价值证据不足 / 资格未确认」，不做虚构排名。

## 4. P2 分类与污染修复（实测验证）

- **A/B/C/D 分类修正**：`grade_claim` 不再仅凭正文是否含"推断"二字判定 C 类；C 类仅当声明以显式结构化前缀（`【推断】`/`【推测】`/`（推断）`/`推断·`）开头才成立，其余非 A 声明保守归 B。A 类须同时满足"声明已核验 + 来源已核验 + 非候选 + 适用范围正确 + 无未解决冲突"，任一不满足降级为 B。
- **档案污染修正**：`build_research_dossier` 去重键由 `等级|正文` 改为 `等级|正文|来源`，避免"同正文不同来源"丢失来源信息。
- **方向串味验证**：方向专属声明（claim 50→方向01、claim 51→方向02）在库中本就各只关联一个方向；新增回归测试 `test_dossier_does_not_leak_other_direction` 锁定"方向01 证据不得含 claim51、方向02 证据不得含 claim50"。

## 5. 缺失资料清单（按对择校判断的影响排序）

1. **2028 招生目录**（五校）：决定 2028 正式资格，目前全部未发布 → 最高优先级。
2. **分口径名额**（目录计划/统考计划/实际录取）：库内 0 行 → 无法量化统考竞争。
3. **四校已核验证据**：目前全为占位 → 无法与北邮做同标准比较。
4. **院校层次/学科评估/导师与实验室**：无结构化数据 → 影响"学校与专业实力"判断。
5. **复试规则与报录比**：无数据 → 影响"考试风险"层。
6. **Phase 2A–2D 原始文件**：工作区不存在（与 Phase 6.1 库存一致），无独立原始研究资料可转化。

以上缺口均已写入系统（`build_risk_gaps`）并在驾驶舱/风险页按影响力排序展示，不虚构、不补零。
