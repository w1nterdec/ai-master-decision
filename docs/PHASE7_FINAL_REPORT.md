## 2. 验收六问（Q1–Q6）直接回答

**Q1 北邮为什么值得考虑？**
北邮 005 人工智能学院 **085410 电子信息（人工智能）** 是专业学位，2027 目录计划合计 **132 人（含推免）**，方向01 考 **801 通信原理**、方向02 考 **408 计算机学科基础**，均考 **数学一**。方向02 的 408 与用户"信计 + AI 工程/算法"背景契合。**但这是 2027 历史事实，2028 正式资格未确认**——只能说明"历史上值得研究"，不足以独立支撑最终决策。

**Q2 北邮方向01 与方向02 有什么区别？**
- **事实（已核验·2027）**：方向01 = 801 通信原理、目录计划 43 人（含推免）；方向02 = 408、目录计划 89 人（含推免）。两方向均为专硕、均考数学一、均含推免。
- **推断（待核实，非事实）**：方向01 偏通信/网络、方向02 偏算法/系统/数据（由考试科目推断）；导师与培养方案差异官方未逐方向列出，**未知**。
- **口径红线**：43/89/132 全部是"目录计划（含推免）"，**非统考计划、非实际录取**，不能直接换算"哪个更易上岸"。

**Q3 其余四校有哪些值得考虑的具体招生路径？**
已识别候选路径（均**无任何已核验证据**，仅候选占位）：
- 电子科大：008/028 学院 085404 计算机技术（028 科目待核）
- 东南：009 学院 085410 人工智能（408）
- 合工大：005 人工智能（408）、021 卓工、023 创新学院（后两者科目待核）
- 西南交大：004/048 学院 085410 人工智能（408）
系统对四校统一显示"培养价值证据不足 / 资格未确认"，**不因资料少给低分、不因北邮资料多就认定更好**。

**Q4 已核实的"培养 / 就业 / 考试风险"差异是什么？**
唯一跨校可用差异是**考试科目**：北邮方向01 = 801、其余多数路径 = 408。名额、培养、就业、竞争、复试等维度**均无已核实数据**，不能给出可信差异。所有"差异"结论都已用"事实/推断"标签分离，推断不冒充事实。

**Q5 系统能否为"不二战"用户解释"哪些值得读 / 值得考 / 风险不可接受"？**
**能，且是定性、可核查的。** 四层解释（`decision_policy.py` + 驾驶舱/风险页渲染）：
- **L1 值得读**：当前仅北邮有"培养价值证据不足 → 可纳入候选研究"的弱结论，其余四校因无证据暂停。
- **L2 值得考**：所有路径均因 **"2028 资格未确认"** 被阻断（"不二战"用户最该关注的硬门槛）。
- **L3 失败后备**：显式携带"仅一次机会、不二战"全局政策，落空后果按终局性代价表述，不被情景倍率稀释。
- **L4 动态偏好**：仅在前面允许时使用；演示权重显式标注"不可作最终结论"。
- **风险不可接受项**：集中在"2028 资格未确认 + 分口径名额缺失"，系统按影响力排序展示，不编概率。

**Q6 什么信息会改变这个选择？**
按对决策的影响排序，补齐后判断会变：
1. **2028 五校招生目录**（决定正式资格，当前全未发布）——最高优先级；
2. **分口径名额**（统考计划 / 实际录取）——决定"哪个更易上岸"能否比较；
3. **四校已核验来源**（当前全为占位）——决定能否与北邮同标准比较；
4. **院校层次 / 学科评估 / 导师与实验室**——决定"学校与专业实力"；
5. **复试规则与报录比**——决定"考试风险"层。
> 在 ① 之前，系统对任何"最终择校排名"都判定为不可接受；补齐 ①②③ 后即可进入可比较状态。

## 3. 诚实结论

- **已完成**：北邮 2027 官方事实结构化、方向差异按"事实/推断"分离、四校候选路径识别、四层决策解释接入、资格闸门硬化、292 项测试全绿。
- **无法完成（证据不足，如实标注）**：2028 资格确认、统考名额比较、四校同标准比较、最终择校排名。这些不是工程缺陷，而是**真实数据尚未发布**。
- **不变量（已回归保护）**：历史≠2028；候选不等于已核验；未知不补 0；不编排名/概率；演示配置不冒充用户偏好。

> **给用户的一句话**：现在系统能负责任地告诉你"北邮 085410 历史上值得研究、方向02 的 408 与你的背景更贴"，但**在 2028 目录发布前，它不会替你拍板**——因为那正是一个"不二战"用户最不能承受的误判。
