# 产品完整性与工程审查 · 2026-10-24

## 本次结论

项目具有独立决策引擎和严格资格闸门，但此前交付主要围绕演示页，未形成可重复安装、可检索研究、跨端完成操作的工作流。本次在保留原引擎和全部管理功能的基础上补齐这些环节。本文记录可核对的问题、修复及实际边界，不把测试通过等同于招生数据真实或商业产品成熟。

## 对标依据

- [研招网硕士专业目录](https://yz.chsi.com.cn/zsml/)：按招生单位、专业与学习方式查询。借鉴按路径身份筛选；官方目录仍是资格核验入口。
- [研招网招生信息公开](https://yzst.chsi.com.cn/zsgs/zsjz/queryall.action)：把招生章程、目录、复试录取材料分开。保留不同年份、不同名额口径和核验状态。
- [易考研](https://www.yikaoyan.com/)：其公开页面介绍并列比较、导出和来源版本说明。本次落实原文对比、筛选导出、原件行号、数据指纹；未复制其数据，未宣称取得其登录后或付费能力。
- [新东方考研智能工具介绍](https://kaoyan.xdf.cn/202606/15241748.html)：其公开介绍强调筛选与考试信息。本次将现有研究实际接入探索和对比；不以缺失资料生成冲稳保或录取预测。

以上为 2026-10-24 查看公开介绍后的功能参考，不构成市场排名或对第三方数据质量的背书。

## 确认并修复的问题

1. **新环境无法复现旧验收**：基线 292 项中 271 通过、9 失败、12 初始化错误。原因包括迁移测试依赖被忽略的本地备份、端到端测试直接读取某个开发者的生产库。现在由已入库 Excel 和官方历史资料迁移生成临时测试库，保留原有断言，取消对本地状态的依赖。
2. **历史官方证据没有进入快速启动**：单跑 Excel 导入只得到候选映射。新增 `scripts/bootstrap.py` 一次完成幂等导入、历史资料迁移和 JSON 投影；保留迁移前备份，不确认任何 2028 资格。
3. **研究资料孤立**：207 条映射只能在静态结论页查阅。新增资料库的全文、多词、学校、路径、主题、层级筛选、分页与 CSV/Excel 下载；探索和对比页面接入相同底稿，保留全部映射。
4. **缺乏回查定位**：导出新增记录编号、Excel 表名和行号、源文件 SHA-256。CI 比对完整投影，拒绝索引错配、悬空记录、重复路径及原件漂移。来源编号无原文 URL 时明确显示为待回查，不伪造链接。
5. **学院路径被对比表覆盖**：电子科大 008 与 028 同专业、同方向名称，原短标签相同导致字典列覆盖。标签现包含学院代码，回归用例验证两列均保留。
6. **关注后驾驶舱异常**：`_render_focus` 使用未定义的 `archive`，已修复并覆盖真实渲染。
7. **来源失效与冲突展示不一致**：学校优势和解释此前只看声明状态；来源失效后仍可能显示为已核实。现同时要求有效来源、非候选、无未解决冲突；冲突数从数据库读取，双方冲突声明降级为待核验。
8. **手机依赖侧栏及宽表**：新增主内容导航，所有高级管理页亦可从页内到达。768px 及以下将表格映射为完整字段卡片，表单纵排、按钮触控面积至少 44px；可切回完整交互表格，保留搜索、排序、列控制、下载。超过 250 行的表继续使用交互表格，避免生成巨大 DOM。
9. **档案写入可被中断截断、标记可互斥失效**：改为同目录临时文件、flush/fsync、原子替换；新增写入失败保护用例。重新加入候选或关注会移除“暂不考虑”标记。
10. **过时缓存和静态措辞误导**：结果页不再无限缓存 JSON；将“截至当前未发布”改为本地快照未收录。修正“多地择校降低同卷撞车”说法，明确并行研究、最终选择一个一志愿。给 P01 补充分组，避免遗漏一条路径。
11. **缺少质量门禁和部署入口**：新增 GitHub Actions 的 Linux/Windows 测试矩阵、Ruff 未定义名称/语法检查、数据一致性校验及测试产物。提供非 root Docker 镜像、持久卷、健康检查及仅绑定本机的 Compose 示例。

## 明确边界

- 仍是 5 校、10 条路径的个人研究系统，不是全国实时择校数据库。207 条是逐路径研究映射，不是 207 个独立官方来源。
- 除已归档并迁移的北邮历史证据外，多数材料仍需核验来源和实际开放范围。来源层级 S1–S4 与已核验状态是两个概念。
- 结构化导师、科研资源、招生名额三类表仍需人工按口径整理。新增原文检索与主题对比，使已有文字可用；没有用文本推测数字后填表，也没有给未知值补零。
- 2028 正式资格和可比较评分仍受原严格闸门约束；本次没有采集完整最新招生目录，也不宣称数据实时更新。
- 一个实例对应个人档案，未实现多用户账户、组织权限、多人协同合并或多设备离线同步；多个浏览器访问同一实例时共享服务器档案。部署到多人环境前需独立设计身份与存储隔离。
- 当前直接依赖已有版本边界，尚未提供跨平台完整哈希锁文件和可复现实验镜像摘要。CI 是持续兼容性验证，不代替数据人工复核。
