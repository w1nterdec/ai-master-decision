## 仍须明确的边界

1. MIT 是项目原创代码许可，不是对第三方研究材料权利的确认。当前缺少逐项再分发授权记录；使用者仍需核对源站条款或另行取得许可。
2. 当前版本更新不删除旧提交中的邮箱、原案例内容，也不撤回已被 fork、克隆或缓存的副本。本地生成提交采用 GitHub noreply 邮箱；GitHub 平台合并署名取决于账户设置，本次平台合并仍保留账户邮箱。本轮不修改账户级设置，也不强制改写公开历史。
3. 模式扫描没有发现命中，不等于所有秘密、隐私、二进制资料和权利问题均已人工审查。
4. 公开代码不等于可以直接将工作台当作多人生产服务；身份隔离、并发和备份仍见工程说明。
