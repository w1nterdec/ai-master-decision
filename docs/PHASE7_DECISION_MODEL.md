# Phase 7.0 决策模型说明（V4.0 四层决策结构）

> 配套代码：`src/decision_system/services/decision_policy.py`（独立只读服务，不改动评分引擎）。
> 审计基准：`docs/V4_MODEL_SEMANTIC_AUDIT.md`（A-01~A-13）。

## 1. 设计原则

1. **本层只解释，不重算分数、不引入新权重。** 所有输入来自 `engine` / `decision_service` / `view_service` / `viewmodels`。
2. **用户「仅一次正式考研机会、不二战」是全局决策政策**，不是某所学校的属性。
3. **动态权重只在第四层用于可补偿因素的比较**，且演示状态必须显式标注。
4. **每一层都输出可核查依据，绝不编造综合评分或上岸概率。**

## 2. 四层结构

```
Evidence Layer        证据闸门（年份/来源/状态/冲突，Phase 6.1 已固化）
        ↓
Eligibility Layer     硬约束（全日制 / 专业代码 / 其他）
        ↓
L1 是否值得读         培养价值 / 就业 / 科研 / 产业生态 / 方向匹配 / 长期发展
        ↓
L2 是否值得考         在 L1 可接受前提下：科目匹配 / 招生稳定性 / 统考名额 /
                      推免影响 / 复试规则 / 竞争风险 / 2028 资格
        ↓
L3 失败后备路径       一志愿 / 有培养价值的调剂 / 直接就业（「不二战」为全局政策）
        ↓
L4 动态偏好比较       仅当前面条件允许时；演示状态必须显式标注
        ↓
Decision Explanation  逐层依据（本阶段交付物）
```

每一层独立输出 `verdict` + `reasons`，渲染见 `blocks.render_decision_explanation`。

## 4. 与现有模型的兼容性

- **保留**：5/10/18 指标树、原有权重计算服务、原有证据闸门、原有情景分析功能（均未改写数值内核）。
- **新增**：独立决策政策层 `decision_policy.py`，只读叠加在引擎输出之上，可单独测试、可单独解释。
- **不重复计权**：四层解释不新增任何加权计算，仅组织已有信号的展示顺序与依据。

## 5. 仍标记为「待处理」的保守项（不强行改动）

A-05 / A-06 / A-08 / A-11 涉及展示映射与指标树结构。任务要求"不得重建数据库、不重写已正确功能、优先最小修改"。这些项若强行改映射可能引起新的口径偏差，故本阶段采取**保守策略**：
- 不在计算层伪造"院校层次""家庭条件"等指标（避免无依据权重）；
- 在四层解释与文档中以"事实/评价分离、优先级排序、演示标注"方式表达，保证用户不被误导；
- 待 2028 目录发布、补登指标后，再在 `V4_DIMENSION_MAP` / `COMPARE_DIMENSIONS` 层面做一次性、可逆的映射修订。

## 6. 关键不变量（回归保护）

- 2028 资格：`applicable_years` 不含 2028 的声明（如全部 2027 北邮资料）一律不能确认 2028。
- 候选声明（`is_candidate`）永不自动升级为已核验。
- 历史事实、考试科目、招生计划分别判断，互不替代。
- 未知不补 0、不进覆盖率分子的"虚构"部分。
