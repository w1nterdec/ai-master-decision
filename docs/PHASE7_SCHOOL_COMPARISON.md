## 1. 北京邮电大学（唯一具备已核验证据）

### 1.1 已核实事实（2027 官方招生目录 + 初试科目调整公告）
- 085410 人工智能为**专业学位**；2027 目录计划合计 **132 人（含推免）**。
- **方向01「人工智能与信息网络」**：目录计划 **43 人（含推免）**；初试 ④ **801 通信原理**（公共课 101/201/301 数学一）。
- **方向02「人工智能与大数据」**：目录计划 **89 人（含推免）**；初试 ④ **408 计算机学科专业基础**（公共课同上）。
- 名额口径：官方原注"招生人数均包含推免生…仅供参考，最终以教育部下达计划为准" → 43/89/132 均为**目录计划（含推免）**，非统考计划、非实际录取。
- 科目调整公告：085410 由 809 数据结构调整为 **408**（落款 2026-06-09），并声明"最终以正式发布目录为准"。

### 1.2 方向01 vs 方向02：事实与推断严格分离

| 维度 | 事实（已核验·2027） | 推断（待核实，**非事实**） |
|---|---|---|
| 初试第四单元 | 方向01=801 通信原理；方向02=408 | — |
| 目录计划（含推免） | 方向01=43；方向02=89 | 统考名额未知（两口径不同） |
| 专业属性 | 均为专业学位、均考数学一、均含推免 | — |
| 备考内容差异 | — | 方向01 偏通信/网络；方向02 偏算法/系统/数据（由考试科目推断） |
| 导师与培养差异 | 官方目录**未逐方向列导师**（claim 53） | 具体导师/实验室/培养方案差异**未知** |
| 与用户背景匹配 | 均接受数学一，符合"接受数学一" | 方向02(408)更贴近"信计+AI工程/算法"背景属**推断**，须经导师/培养方案核实 |

### 1.3 用户当前是否有足够理由重点准备其一？
**证据不足，不能。** 理由：
1. 2028 正式资格未确认（仅有 2027 资料）；
2. 43/89 为含推免口径，统考名额未知，无法直接比较"哪个更易上岸"；
3. 导师与培养方向差异在官方资料中缺失，无法判定"哪个更贴近具身智能/机器人长期方向"。

**建议**：等 2028 目录发布后，用"统考计划数 + 导师研究方向 + 培养方案"三项再判断，当前不应锁定单一方向。

## 3. 对照验收六问（Q1–Q5）

**Q1 北邮为什么值得考虑？**
北邮 005 人工智能学院 085410 是**专业学位**、2027 目录计划 132 人（含推免），方向01/02 均考数学一，且方向02 考 408（与用户"信计 + AI 工程/算法"背景契合）。但**这是 2027 历史事实，2028 资格未确认**，只能说明"历史上值得研究"，不足以支撑最终决策。

**Q2 北邮方向01与方向02有什么区别？**
事实：方向01 考 801 通信原理、目录计划 43 人（含推免）；方向02 考 408、目录计划 89 人（含推免）。推断：方向01 偏通信/网络、方向02 偏算法/系统/数据；导师与培养差异**官方未列、未知**。详见 §1.2 分离表。

**Q3 其余四校有哪些值得考虑的具体招生路径？**
见 §2.1 已识别候选路径。目前**无任何已核验证据**支持"值得考虑"的结论，仅能从考试科目（多为 408）作弱候选推断。

**Q4 已核实差异？**
唯一跨校可用差异是**考试科目**：北邮方向01=801、方向02 与其余四校多数路径=408。名额、培养、就业、竞争等维度**均无已核实数据**，不能给出可信差异。

**Q5 系统能否解释"哪些值得读/值得考/风险不可接受"？**
能基于四层决策解释（L1–L4）给出**定性**结论：当前所有路径 L2 均因"2028 资格未确认"被阻断，L1 仅北邮有"培养价值证据不足→可纳入候选研究"的弱结论；风险不可接受项集中在"2028 资格未确认 + 分口径名额缺失"。详见 `decision_policy.py` 与驾驶舱/风险页。

## 4. 诚实结论

- **已完成**：北邮 2027 官方事实已结构化、方向差异已按"事实/推断"分离、四校候选路径已识别。
- **无法完成（证据不足）**：2028 资格确认、统考名额比较、四校同标准比较、最终择校排名。
- **下一步最该补的证据**（按影响）：2028 五校招生目录 → 分口径名额 → 四校已核验来源登记 → 院校层次/学科评估 → 导师与实验室 → 复试规则与报录比。
