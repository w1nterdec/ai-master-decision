## 5. 给下一阶段的"最该做的一件事"

**采集并登记 2028 五校招生目录**（官方 PDF / 网页），使其通过 `register_source` + `register_claim` 进入已核验证据库，并把名额拆成"目录计划 / 统考计划 / 实际录取"三口径写入 `admission_record`。

这一步完成后，系统才能：
1. 把北邮 2028 资格从"未确认"翻转为"已确认"；
2. 让四校从"候选占位"进入可比较状态；
3. 真正回答用户 Q3/Q4（四校同标准比较、统考名额竞争差异）。

在此之前，系统会持续如实显示"资格未确认 / 证据不足"，这符合"不二战"用户的决策安全。
