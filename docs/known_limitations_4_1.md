分级：**P1** 影响可用性但可绕过 / **P2** 文档或体验问题 / **P0** 阻断性缺陷。
Phase 4.1 自评：**P0 = 0 条**。

| # | 问题 | 性质 | 说明与影响 |
|---|---|---|---|
| P1-1 | 10/10 条路径 2028 资格未确认 | 数据状态 | 硬约束强制「硬约束待确认-不可比较」，系统**不产出任何可比较分数**；界面已显式提示 |

| P2-1 | `is_placeholder` 字段与「本体登记」口径不一致 | Phase 4.0 导入的 83 条引用式来源 `is_placeholder=False` 但无本体；本阶段改用 `is_registered_source()` 判定（非占位模板 **且** 有 url_or_file 或 publisher）。**未改数据**，仅收敛口径 |

## 正确使用边界（重要）

1. 本系统**不得**用于输出录取概率或院校排名（输出结构由 `assert_no_admission_probability()` 强制自检）。
2. 在 2028 资格确认、来源本体登记、证据核验三项完成前，页面的唯一正确输出是
   **「证据不足 / 不可比较 / 当前尚不能形成可靠比较」**。
3. 演示权重、演示情景倍率、演示相关度矩阵**不得**被当作用户正式偏好使用。
4. 界面写入的任何核验结论都必须有操作者与依据；无依据的操作会被服务层拒绝。
