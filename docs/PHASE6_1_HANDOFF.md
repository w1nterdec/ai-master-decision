## 8. 未解决的风险

### 8.1 建模层（M3 审计登记，**本阶段按纪律未改**）

| 编号 | 严重度 | 问题 |
|---|---|---|
| A-02 | **高** | 「不二战 / 仅一次机会」未建模为硬约束或风险代价，仅停留在文字常量 |
| A-03 | **高** | 无任何「失败后果」指标，V4 04「失败风险」实际只覆盖考试不确定性 |
| A-04 | **高** | 情景倍率把「职业发展优先」与「重视报考风险」做成互斥（career 情景把报考可行性压到 20.96%，admission 情景把职业发展压到 24.56%），**没有任何情景能表达用户真实偏好** |
| A-07 | 中 | 无「院校层次 / 学科评估」指标 |
| A-09 | 中 | A 目标必备分组为「研究培养」，与用户最看重的「就业质量」不匹配 |
| A-10 | 中 | 修改演示配置后 `is_demo` 不变，用户易误认为已确认 |
| A-05 / A-06 / A-11 / A-12 / A-13 | 低–中 | 展示映射与计算语义不一致等 |
| A-08 | 中 | 无「家庭可承受能力」「与家庭地理关系」指标 |

> A-01（四页缺演示权重提示）**已在本阶段修复**。

### 8.2 数据层

- 48 条候选声明**无一条标注适用年份**，即便补齐本体也不能直接用于任何年度判定。
- 候选声明 `#6`（写"方向02"）与 `#7`（写"方向01"）在库中**同时关联 P01 与 P02**，历史研究资料在方向维度不可靠。

### 8.3 系统层

- 生产库不在版本库中，异地环境重建依赖 `scripts/import_excel.py` + Phase 5.0 迁移脚本；端到端用例会 skip。
- 对外 Web 使用**单一共享口令**（环境变量注入），无轮换机制、无分用户审计。

## 9. 下一步建议（需用户批准后方可实施）

1. **先解决 A-02 / A-03**：把「仅一次机会、不二战」建模为不可补偿的硬约束与失败代价，而不是可加权指标。这是本系统当前最大的语义缺口。
2. **再解决 A-04**：重构情景机制，使"职业发展优先"与"重视报考风险"可同时成立（例如改为独立的风险闸门而非倍率）。
3. **补齐演示权重提示的最后一环**：决策树页修改演示配置后仍标记 `is_demo=True`（A-10），建议增加显式"确认为我的偏好"入口并前置到驾驶舱。
4. **等 2028 目录发布后**：优先补 D 节第 1–5 项，届时北邮案例才能从"值得研究"升级为"可决策"。
5. **若要研究 140500**：需单独登记路径并建立方向级证据，本阶段有意未做。
